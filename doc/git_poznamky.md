# Práca s Gitom

Git je nástroj na správu verzií projektu.

GitHub slúži na online ukladanie a zdieľanie repozitárov.

## Základné pojmy

- Repository – repozitár, v ktorom sa nachádza projekt.
- Commit – uloženie zmien v projekte.
- Push – odoslanie zmien na GitHub.
- Pull – stiahnutie zmien z GitHubu.
- Clone – vytvorenie lokálnej kópie repozitára.
